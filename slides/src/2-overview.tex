\subsection{Resiliency Real-Time and Certification}

\begin{frame}{Overview}
    \begin{block}{Types of AI (TAI)}
        \begin{itemize}
            \item \textbf{Connectionists:} Optimization and gradient-based (e.g., NNs and transformers).
            \item \textbf{Bayesian:} Probabilistic outcomes.
            \item \textbf{Symbolists:} Logic-based and explainable (e.g., decision trees and prolog).
            \item \textbf{Analogizers:} Similarity-based (e.g., k-NN and SVM).
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{AI Automation Levels}
        The EASA define three level of automation:
        \begin{itemize}
            \item \textbf{Level 1:} Collaborative robots, that work side-by-side with humans without indipendence. For example a robot harm that help a worker.
            \item \textbf{Level 2:} Autonomous systems that operate in a closed (i.e., predefinited, where requirements are well known) environments. For example a drone that map a closed environment like a factory.
            \item \textbf{Level 3:} Autonomous systems that operate in a open environments and that can adapt their goal and behaviour. For example a autonomous driving car.
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{Safety Standards}
        The SIS (Safety Integration System) have the objective to mitigation tisks throught programmable functions embedded in the system.
        \begin{itemize}
            \item \textbf{Measures:} SIL (IEC 61508), ASIL (ISO 26262), DAL (DO-178C).
            \item \textbf{Gap:} Critical levels require $10^{-9}$/h failure probability; the AI model reachs around 99\% accuracy. In a AI-based System (e.g., ADAS) we can have a system failure without a software or hardwere failure
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{When Introducing AI}
        The ISO 5469 defined three scenario that correlate the type of AI and their usage in a complex system.
        \begin{itemize}
            \item \textbf{Class I:} Deterministic AI (e.g., symbolist) $\Rightarrow$ Formally verifiable $\Rightarrow$ Complies with traditional FuSa.
            \item \textbf{Class II:} Partial verifiable AI model $\Rightarrow$ Requires to be monitored by a runtime checker (\textit{Safety Bag} techniques) that take a safe decision in case of AI error.
            \item \textbf{Class III:} Totally unverifiable AI model $\Rightarrow$ Safety responsibility cannot be taken by the engineers (e.g., complex ADAS).
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{How Introducing AI}
        \begin{itemize}
            \item \textbf{Product:} AI-based safety functions that are trained offline and then embedded in the system.
            \item \textbf{Runtime:} AI models that update/adapt online during system execution.
            \item \textbf{Process:} AI models are used to design/develop/test the system.
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{Product}
        AI-based safety functions that are trained offline and then embedded in the system.
        \vfil
        We speak about \textit{intended functionality}: a high level of intructions set eather than specific statements.
        \begin{itemize}
            \item Explainable and Interpretable: \textit{Class I} scenario.
            \item Back box: \textit{Class II} scenario.
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{Runtime}
        AI models that update/adapt online during system execution.
        \begin{itemize}
            \item \textbf{Safety Bag:} A RunTime checker chooses a safety beheviour rather than the AI choice.
            \item \textbf{Safe Adaptation:} Both model and training algorithm are conformed to a standard.
            \item \textbf{Limted adaptation:} The parameters chainging is clapped.
            \item \textbf{Limted Actuation:} The magnitude of the AI action is clapped.
            \item \textbf{Library-based Offline:} A deterministic choice (i.e, \texttt{if/else}) choose among a set of model that are conform to safety standard.
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Overview}
    \begin{block}{Process}
        AI models are used to design/develop/test the system.
        \begin{itemize}
            \item \textbf{Specification:} NLP (e.g., transformers) models for hazard analysis.
            \item \textbf{Design/Testing:} Code and test code base.
            \item \textbf{AutoML:} Reinforcement learning for hyperparameter tuning.
        \end{itemize}
    \end{block}
\end{frame}
