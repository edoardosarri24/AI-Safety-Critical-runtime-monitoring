\section{Runtime Monitoring}

\subsection{Resiliency Real-Time and Certification}

\begin{frame}{Runtime Monitoring}
    \begin{block}{Runtime Assurance (RTA)}
        Runtime Assurance (RTA) system is able to handle the complexity of AI model without handle it directly.
        \begin{itemize}
            \item \textbf{Concept:} Instead of trying to certify a highly complex or non-deterministic AI module, we can wrap it in a runtime monitor (i.e., a runtime checker) that switches to an assured recovery function if it recognises a failure.
            \item \textbf{Modularity:} The system remains certified even if we totally change the AI model: the certification is not based on the quality of AI.
            \item \textbf{Versatility:} Can be applied at any system level (e.g., controllers, actuators) and with one monitor for each SIS.
        \end{itemize}
    \end{block}
\end{frame}
